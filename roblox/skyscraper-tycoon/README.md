# 🏙️ Небоскрёб Тайкун (Roblox)

Гриндилка-тайкун: строишь свой небоскрёб этаж за этажом. Каждый этаж приносит деньги,
чем выше башня, тем больше бонус. Но наверху дует ветер, который ломает этажи.

## Как играть

1. Заходишь, получаешь свободный участок (до 6 игроков на сервере).
2. Внизу выбираешь тип этажа и жмёшь «Построить» (можно держать кнопку).
3. Этажи приносят деньги в **кассу**. Забирай их кнопкой «Собрать» или вставай на зелёную площадку.
4. Новые типы этажей открываются с высотой.
5. Раз в 2–4 минуты приходит **шторм**: этажи выше безопасной высоты могут повредиться и перестают приносить доход, пока их не починишь.
6. Достиг нужной высоты → **реконструкция**: всё сбрасывается, но доход навсегда растёт.

## Этажи

| Этаж | Доход/с | Цена | Открывается |
|---|---|---|---|
| 🏠 Квартиры | 1 | 10 | сразу |
| 💼 Офис | 8 | 120 | 5 эт. |
| 🍔 Ресторан | 50 | 1.5K | 15 эт. |
| 🏨 Отель | 300 | 20K | 30 эт. |
| 🎰 Казино | 2K | 250K | 50 эт. |
| 👑 Пентхаус | 15K | 3M | 80 эт. |

Каждый следующий этаж дороже на 5% (`FLOOR_COST_GROWTH`).

## Множители дохода

- **Высота:** +10% за каждые 10 этажей.
- **Реклама:** +10% за уровень (до 25 уровней).
- **Реконструкция:** +50% навсегда за каждую.
- **Геймпасс x2:** удваивает весь доход.

## Улучшения

| Улучшение | Что даёт | Цена |
|---|---|---|
| 🏗️ Стабильность | +10 этажей, которые не ломает ветер (база 15) | 200, ×2.2 за уровень |
| 📢 Реклама | +10% дохода | 500, ×1.9 за уровень |
| 🧑‍💼 Менеджер | Деньги идут сразу на счёт, без кассы | 5000, один раз |

## Реконструкция (перерождение)

- Нужно 40 этажей, потом +20 за каждую следующую (40 → 60 → 80 ...).
- Сбрасывает деньги, башню, стабильность и рекламу.
- Менеджер остаётся.
- Даёт +50% к доходу навсегда.

## Что ещё есть

- 💾 Сохранение прогресса (DataStore) и автосохранение каждую минуту.
- 💤 Офлайн-доход: 25% от дохода за время отсутствия, максимум 8 часов.
- 🏆 Таблица игроков: этажи и реконструкции.
- 📱 Интерфейс подходит для телефона.
- 🌪️ Предупреждение о шторме и тряска камеры.
- 🔒 Сервер проверяет все действия, читерить через клиент не выйдет.
- 🎁 Ежедневная награда: серия из 7 дней, награда растёт (от 2 до 30 минут дохода).
- 🎟️ Коды: `NEBO`, `VETER`, `ZOLOTO`. Свои коды добавляются в `Config.Codes`.
- ✨ Золотой час: раз в 20–30 минут весь сервер получает x2 доход на 3 минуты.
- 🛗 Лифт: синяя площадка на участке поднимает на крышу любой башни.
- 🏆 Табло рекордов в центре карты: самые высокие башни со всех серверов.

Все цифры баланса лежат в `src/shared/Config.luau`.

## Установка в Roblox Studio (копированием)

1. Открой Roblox Studio → **New** → **Baseplate**.
2. В окне **Explorer** создай скрипты так (правый клик → Insert Object):

```
ReplicatedStorage
└── Shared              (Folder)
    ├── Config          (ModuleScript)  ← src/shared/Config.luau
    └── Format          (ModuleScript)  ← src/shared/Format.luau

ServerScriptService
├── Main                (Script)        ← src/server/Main.server.luau
├── DataService         (ModuleScript)  ← src/server/DataService.luau
├── TowerBuilder        (ModuleScript)  ← src/server/TowerBuilder.luau
└── Leaderboard         (ModuleScript)  ← src/server/Leaderboard.luau

StarterPlayer
└── StarterPlayerScripts
    └── UI              (LocalScript)   ← src/client/UI.client.luau
```

3. В каждый скрипт полностью вставь код из соответствующего файла (стерев то, что там было).
   **Имена должны совпадать точно**, иначе скрипты не найдут друг друга.
4. Нажми **Play**. Участки, башни и интерфейс появятся сами.

### Чтобы работали сохранения

1. **File → Publish to Roblox** (опубликуй место).
2. **Home → Game Settings → Security** → включи **Enable Studio Access to API Services**.

Без этого игра работает, но прогресс не сохраняется (в Output будет предупреждение).

### Геймпасс x2 дохода (по желанию)

1. Creator Hub → твоя игра → **Monetization → Passes** → создай пасс.
2. Скопируй его ID в `Config.GAMEPASS_DOUBLE_INCOME`.
3. Справа появится кнопка «⚡ x2 Доход».
